## 原问题与当前处理

- 默认撤销按新到旧选择全部待处理记录，重跑产生的空记录不再遮蔽旧资源。增加现场名过滤，显式 Latest 仍是较窄的选择。
- 逐变更记录撤销进度；保留的 Tailscale 可选项以后可以补做，兼容旧 Undone 记录。注销失败是可重试错误，并阻断后续卸载。
- 多运行的档案、TrustedHosts、注册表和接入结果按同一顺序预览、执行。档案原始字节、生成内容及备份均有 hash 保护。
- 备份和变更先持久登记，再原子替换结果文件。失败时保留必要备份；运行临时目录最后清理。01 的自动回滚保留更新后的撤销进度。
- GUI 公开配置只保存随机凭据引用。实际凭据位于当前用户 DPAPI 存储，目录 DACL 仅当前用户/SYSTEM；复制到别的路径或用户后重新输入。
- GUI 使用统一参数引用、保留进程句柄和真实退出码，运行期间禁用其他操作。撤销必须先成功预览，其他任务会使旧预览失效。
- 新增直连电脑流程。初始化必须取得 IP 并产生本次新结果；旧结果不再充当成功依据。本机未连接 Tailscale 时明确提示登录，不隐藏等待授权。
